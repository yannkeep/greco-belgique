# Belgique dans le viseur du GRECO

Site documentaire statique consacré au suivi de la Belgique par le GRECO (Conseil de l’Europe).

## Stack

- HTML5 sémantique
- CSS natif
- JavaScript natif
- aucune dépendance
- aucun build
- aucun générateur

## Déploiement GitHub Pages

Le dépôt est prévu pour être publié depuis la branche `main`, racine `/`.

Dans GitHub : **Settings → Pages → Deploy from a branch → main / root**.

## Contenu

- `index.html` — synthèse grand public
- `cycles.html` — chronologie et conformité
- `article-32.html` — transparence administrative
- `analyse.html` — analyse critique
- `sources.html` — bibliographie et méthode
- `assets/styles.css`
- `assets/app.js`
